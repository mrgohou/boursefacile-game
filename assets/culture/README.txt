PACO Héritages BRVM — illustrations originales générées pour ce projet, novembre 2026.

pions-atlas.png : 20 objets, 1122 x 1402, cadres individualisés dans cultural_catalog.dart.
villes-atlas.png : 24 dioramas, 6 colonnes x 4 lignes, 1536 x 1024, fond alpha transparent.

Les modèles de référence sont des objets et architectures évoqués dans le brief utilisateur. Aucun asset de Township ou Candy Crush n'est distribué. Ces illustrations stylisées ne prétendent pas reproduire exactement un objet patrimonial réel.

Les images restent entières. Flutter Canvas et Flame Sprite sélectionnent leurs cadres lors du rendu. Un même atlas décodé est partagé dans l'interface pour limiter les allocations.
