# Ressources réutilisées

Les visuels PACO existants sont repris sans transformation : 37 bâtiments/passants, 11 poses de Paco et 10 tuiles. Le terrain tropical original créé pour la version précédente est réutilisé. Les 11 WAV originaux restent ceux de PACO. Les JSON du catalogue compagnon et leur manifeste de provenance sont conservés sous `app/src/main/assets/companion/`.

L'icône Android emploie la pose d'accueil de Paco. La famille d'interface provient de Nunito sous SIL OFL ; des instances statiques 400/600/700/900 sont nommées Paco Rounded pour rester lisibles aussi sur API 24/25. La licence originale figure dans `Nunito-OFL.txt`. Les fichiers sont embarqués ; aucune police ou image n'est téléchargée pendant le jeu.
