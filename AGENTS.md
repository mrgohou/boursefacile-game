# PACO Kotlin
- Native Android: Kotlin, Jetpack Compose, MVVM. No Flutter runtime or Unity dependency.
- Pure game/economy rules in domain, persistence and assets in data, Compose in ui.
- All money fictitious, offline simulation. No live financial service or guaranteed revenue.
- Persist transactions before publishing state; unique rewards; backward-compatible save format.
- Accessible labels, 48 dp controls, scalable text, reduced motion, lifecycle-safe audio/timer.
- Do not add keys, credentials or signing material to the repository.
