# PACO mobile — règles de contribution

- Flutter + Flame ; Material Design 3 ; français ; Android en premier, iOS scaffoldé.
- Jeu pédagogique, argent et entreprises fictifs. Aucun conseil financier personnalisé.
- Pas de secret, compte de service ou certificat de signature dans le dépôt.
- Le mode démo local est explicitement distinct d'un service connecté sécurisé.
- Les récompenses, soldes et transactions connectées sont autoritaires côté serveur.
- Contrats partagés documentés, changements courts, tests des invariants et revue avant intégration.
- Aucun déploiement, ressource facturée ou publication store automatique.
- Ne pas modifier les fichiers attribués à un autre agent sans coordination.
- Accessibilité : cibles tactiles 48 dp, SafeArea, texte redimensionnable, état non porté uniquement par la couleur, reprise explicite.
